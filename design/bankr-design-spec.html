Bankr · design spec

The three-destination AI-first shell — desktop and mobile

Today, Money, and You: a pinned safe-to-spend figure, a conversation stream, and a fixed answer-block vocabulary the agent composes from. This spec covers both breakpoints and the components shared between them.

Today / chat stream — live in web Money, You, full nav — spec only, not yet built

How to read this

Colors and type are copied verbatim from web/src/index.css — that file is the source of truth. If tokens change there, update the :root block at the top of this file to match; don't hand-tune a separate palette. The Today destination (pinned number, goal card, stream, chips) is already implemented in web/src/pages/HomePage.tsx against real endpoints. Money and You below are designed but need backend work first — a commitment/recurring-charge model for Money, and a user-editable rules record for You. See the status table at the bottom.

Layout

Desktop gets a persistent sidebar. Mobile gets a bottom tab bar.

Same three destinations, same content, same pinned figure — the nav pattern changes because desktop has room for a permanent rail and mobile doesn't. Toggle between them below; each keeps its own Today/Money/You state.

Answer vocabulary

Six blocks the agent composes from — shared by both platforms.

Free-form generation is what makes AI apps feel unreliable. Constrain the model to this fixed set of components and every answer stays legible without looking improvised. This is the contract between the agent's output and whatever renders it, on either platform.
