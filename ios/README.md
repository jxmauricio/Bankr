# Bankr iOS

SwiftUI app. The project itself (`Bankr.xcodeproj`) is generated by
[XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml` — don't
edit the `.xcodeproj` directly, edit `project.yml` and re-run:

```bash
brew install xcodegen   # if not already installed
xcodegen generate
```

Re-run `xcodegen generate` any time you add/remove a source file, or change
`project.yml`, so the project picks it up.

## Dependencies

- **LinkKit** (Plaid Link SDK) via SPM, pinned to `7.1.0` in `project.yml`.
  Uses `https://github.com/plaid/plaid-link-ios-spm.git` — Plaid's own
  README recommends this lightweight pointer repo over the main
  `plaid-link-ios` repo, which downloads its full git history (~1GB) under
  SPM. Verified against the real repo/release/`Package.swift`/demo source at
  that tag, not guessed.

## Layout

- `Bankr/App/` — app entry point, `SessionStore` (holds the backend session
  token), `RootView` (signed-out → `WelcomeView`; signed-in →
  `PostSignInGateView`, which routes signed-in users through
  `LinkBankAccountView` → `GoalSetupView` → `DashboardView` based on
  `GET /dashboard/net-worth` and `GET /dashboard/goal-progress`)
- `Bankr/Onboarding/WelcomeView.swift` — Sign in with Apple screen
- `Bankr/Onboarding/LinkBankAccountView.swift` — Plaid Link integration:
  fetches a link token from `POST /linked-accounts/link-token`, launches
  Plaid Link via `LinkTokenConfiguration`/`Plaid.createPlaidLinkSession`,
  and on success posts the resulting `public_token` to `POST /linked-accounts`
- `Bankr/Onboarding/GoalSetupView.swift` — guided goal-type + target
  amount/date screen, posts to `POST /goals`
- `Bankr/Dashboard/DashboardView.swift` — net worth, goal progress, monthly
  rollup, itemized spending/income; backed by `DashboardViewModel`
- `Bankr/Chat/ChatView.swift` — the AI-agent-first surface: a simple chat
  screen posting to `POST /chat`, reachable from the dashboard toolbar
- `Bankr/Networking/BankrAPIClient.swift` — the only thing that talks to the
  backend; never calls Plaid or Claude directly (see `../backend/README.md`)

## Run

Open `Bankr.xcodeproj` in Xcode and run on a simulator, or from the CLI:

```bash
xcodebuild -project Bankr.xcodeproj -scheme Bankr \
  -destination 'platform=iOS Simulator,name=iPhone 17' build
```

The backend must be running locally (`cd ../backend && uvicorn app.main:app --reload`)
with real `PLAID_CLIENT_ID`/`PLAID_SECRET` set for bank linking, sign-in, and
every dashboard/goal call to succeed — `BankrAPIClient.baseURL` currently
points at `http://localhost:8000`.

**Verified fully end-to-end in the simulator**, including real Plaid Link:
launched the app with a seeded (no-accounts-yet) user, tapped through the
actual `LinkBankAccountView` → Plaid Link UI → Plaid Sandbox institution
picker → sandbox login (`user_good`/`pass_good`) → account selection, and
confirmed the resulting `public_token` reached the backend, got exchanged,
and synced real (sandbox) account data — the app correctly advanced straight
to `GoalSetupView` afterward, and `GET /dashboard/net-worth` reflected the
synced balances. `DashboardView` and `ChatView`'s empty state were verified
the same way in an earlier pass (seeding a user directly via
`app.services.sync_service`/`goal_service`, bypassing real Sign in with
Apple, which needs an Apple ID signed into the simulator). Sending an actual
chat message needs a real `OPENROUTER_API_KEY` on the backend (currently only
mock-verified server-side, see `../backend/README.md`).
